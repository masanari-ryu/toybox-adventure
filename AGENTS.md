# Public game pages

Keep the public introduction inviting and brief. The manual is for controls, not strategy.
Weapon/item catalogs may show names, pictures, general abilities and inherent costs/risks.
Never publish pickup locations, difficulty restrictions, unlock conditions, enemy drops,
spawn probabilities, routes, boss tactics, nightmare wave/resource/carryover details, or
Parupun probabilities and specific random outcomes. Additions to game code do not authorize
adding acquisition instructions to public pages. Keep discovery inside the game.

Player-visible game text must use kana, numbers and ordinary symbols, without Latin letters
or kanji. Preserve existing difficulty, AI, controls and stage layout unless requested.
